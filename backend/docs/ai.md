### AI Insights API SPEC

All endpoints require Bearer Token (JWT) and are scoped to the authenticated user. Insights are generated by the Gemini model and persisted in ai_insights.

Insight types : monthly_summary, weekly_summary, savings_tips, budget_alert.

AI Insight Data Model :

| Field | Type | Description |
|-------|------|-------------|
| id | integer | Auto-generated primary key. |
| user_id | integer | Owner of the insight. |
| insight_type | string | monthly_summary, weekly_summary, savings_tips, or budget_alert. |
| period_start | string \| null | Period start (YYYY-MM-DD); null for savings_tips/budget_alert. |
| period_end | string \| null | Period end (YYYY-MM-DD); null for savings_tips/budget_alert. |
| content_json | object | Generated insight content (structure depends on insight_type). |
| created_at | string | Creation timestamp (ISO 8601). |

## List Insights

Endpoint : GET /api/insights

Authentication : Bearer Token (JWT)

Request Header :

- Authorization : Bearer <token>

Request Body :

None

Request Body (Success) :

```json
[
  {
    "id": 7,
    "user_id": 1,
    "insight_type": "monthly_summary",
    "period_start": "2026-07-01",
    "period_end": "2026-07-31",
    "content_json": {
      "summary": "You had a strong savings month with income comfortably above expenses.",
      "highlights": ["Healthy savings rate", "Stable income"],
      "concerns": ["Dining spending is rising"],
      "recommendations": [
        { "title": "Cap dining", "detail": "Set a weekly dining limit to protect savings." }
      ],
      "topSpendingCategory": "Makan & Minum",
      "estimatedMonthlySavings": 7500000,
      "healthScore": 82
    },
    "created_at": "2026-07-16T03:56:01.000Z"
  }
]
```

Request Body (Failed) :

```json
{ "message": "Failed to fetch insights" }
```

## Generate Insight

Endpoint : POST /api/insights/generate

Authentication : Bearer Token (JWT)

Request Header :

- Authorization : Bearer <token>
- Content-Type : application/json

Request Body :

```json
{
  "type": "monthly_summary"
}
```

- type : string, required, one of monthly_summary, weekly_summary, savings_tips, budget_alert
- categoryId : integer, required when type is budget_alert

Request Body (Success) :

```json
{
  "id": 8,
  "user_id": 1,
  "insight_type": "monthly_summary",
  "period_start": "2026-07-01",
  "period_end": "2026-07-31",
  "content_json": {
    "summary": "You had a strong savings month with income comfortably above expenses.",
    "highlights": ["Healthy savings rate", "Stable income"],
    "concerns": ["Dining spending is rising"],
    "recommendations": [
      { "title": "Cap dining", "detail": "Set a weekly dining limit to protect savings." },
      { "title": "Automate savings", "detail": "Move savings to a separate account on payday." },
      { "title": "Review subscriptions", "detail": "Cancel unused recurring payments." }
    ],
    "topSpendingCategory": "Makan & Minum",
    "estimatedMonthlySavings": 7500000,
    "healthScore": 82
  },
  "created_at": "2026-07-16T03:56:01.000Z"
}
```

Request Body (Failed) :

```json
{ "message": "Insight type is required" }
```

```json
{ "message": "Unknown insight type" }
```

```json
{ "message": "Failed to generate insight" }
```

### Notes

- type must be one of the four supported insight types.
- budget_alert requires categoryId; if omitted it throws and returns 500.
- content_json shape by type:
  - monthly_summary / weekly_summary: summary, highlights[], concerns[], recommendations[{title, detail}], topSpendingCategory, estimatedMonthlySavings|estimatedWeeklySavings, healthScore (integer 0-100).
  - savings_tips: overallTip, tips[{category, title, detail, estimatedSavings}] (exactly 4 tips).
  - budget_alert: severity ("info"|"warning"|"critical"), title, message, suggestions[].
- AI content is non-deterministic.
